# Campus Placement Management System

A small, browser-only demo of a campus placement portal. Open `index.html` in a modern browser; no installation or server is required.

## Features

- Student and admin registration and login
- Sample placement listings for TCS, Infosys, and Wipro
- Student applications and application status tracking
- Admin controls for listings and application statuses
- Browser `localStorage` persistence

## Demo flow

1. Register an account and select `ADMIN` to add or remove company listings and update application statuses.
2. Log out, register a `STUDENT` account, and apply to a listing.
3. Log in as the admin again to review the application.

## Limits

This is a front-end demonstration. Accounts, passwords, listings, and applications are stored in the current browser's local storage. It has no server, database, password protection, or real authentication. Do not use real personal data or passwords. Clearing browser storage removes the demo data.
